CARM：避免概率比相互抵消的响应掩码

LLM 强化学习中，rollout 和训练策略不一致会导致离策略样本。几何平均概率比可能让正负漂移抵消；CARM 先取逐 token 对数比的绝对值再平均，建立被接受响应的偏移约束。作者在数学与代码基准报告改善，理论与实验都围绕响应级离策略控制。

HC-DLM：连续潜变量与离散 token 联动去噪

离散扩散并行采样可能丢失共同解码 token 的依赖，连续模型又缺少有效 token 配置约束。HC-DLM 用持续的连续潜变量作为生成状态，每步读取 token 并反馈给下一步潜变量，训练目标来自似然的变分界。摘要在 Sudoku、Countdown 与 LM1B 上报告同规模基线改善。

2026-10-09
研究问题

现有agent RL受on-policy推理瓶颈约束：任务超出模型当前能力边界时有效轨迹极其稀疏，训练常崩溃。

DiffusionART：高效、稳定、可扩展的扩散模型强化

2026-10-09
研究问题

在线RL微调扩散模型受黑盒奖励约束：Flow-GRPO等逆过程方法受差信用分配限制效率，DiffusionNFT等正过程方法高效但依赖精心调参的EMA off-policy训练才稳定。

核心贡献

揭示NFT风格目标含隐藏的正向-反向一致性力（joint正负训练仅部分抵消）；DiffusionART将每提示奖励聚合为共享奖励提升方向，构造上消除一致性力，加trust-region掩码二次更新实现漂移自适应恢复且无需EMA调参；支持成对奖励模型(DiffusionART-Pairwise)。

结果与条件

HunyuanVideo-13B上，以等权视觉与运动质量奖励，DiffusionART达到DiffusionNFT与Flow-GRPO-Fast晚期平均奖励水平分别少用12.02与11.72倍GPU小时，同时平均训练奖励高28.8%与53.0%。

无需可微奖励模型；更少每提示样本仍有效；图像与视频生成均验证。

残差建模弥合机器人学习回归与生成策略差距

2026-10-09
研究问题

流匹配/扩散策略常优于MSE直接动作回归，差距通常归因于多模态演示；从统计建模视角，动作预测残差形态塑造策略优化，MSE梯度过度偏向大残差观测损害优化。

核心贡献

分析真实机器人演示数据：残差尺度随状态显著变化且重尾。提出异方差Student-t动作回归(HT-Policies)：学习输入相关残差尺度并降低重尾影响；单前馈预测动作块，可复用预训练流匹配策略骨干。

四个仿真基准+真实机器人评估上，HT-Policies成功率与生成策略基线相当（从零训练与预训练VLA/WAM微调），训练与推理更快。

真实演示数据残差重尾；HT-Policies复用预训练流匹配骨干；四仿真+真实机器人。

S3R：基于自稀疏投机解码的快速忠实RL Rollout

2026-10-09
研究问题

长上下文RLVR快速rollout需减少KV缓存流量但不改变策略优化所用的响应组；直接稀疏采样会改变响应组分布，逐响应精确重加权也无法恢复期望稠密策略更新。

核心贡献

S3R用稀疏注意力提议token，全注意力验证+精确投机采样生成响应；草稿与验证共享同一策略参数，无需独立草稿模型；KV感知调度器限制重复卸载/恢复。

结果与条件

长上下文数学推理上，S3R使Qwen3模型端到端训练吞吐达自回归rollout的1.39倍（约1.35倍），任务性能相当；稀疏草稿预算下稳定训练而直接稀疏采样不稳定。

注意力占自回归解码kernel时间72-76%；稠密验证仍需完整历史KV缓存；Qwen3模型。

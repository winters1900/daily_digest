OneSearch-VL：图像与视频的统一多模态深度研究 Agent

2026-10-09
Keywords

方法论文 · deep research / multimodal agent / evidence grounding / retrieval

研究问题

单图/多图/视频深度研究需不同视觉操作但共享视觉接地、外部检索与事实组合工作流；关键挑战是保持局部视觉锚点、实体关系、来源支撑事实与答案操作间的依赖。

核心贡献

OneSearch-VL 以视觉接地证据图(VGEG)为中心统一 agent，编码依赖为共享任务级参考用于数据构建/过程监督/操作级评估；VGEG 数据引擎构建多图/视频问题并过滤专家轨迹；EVGR 奖励监督 RL 阶段证据可追溯性与视觉接地。

OneSearch-VL-8B 相对带工具 Qwen3-VL-8B 在两个新基准上提升 20.2 与 17.6 个百分点，并在 7 个图像基准与 VideoDR 上显著增益。

2026-08-20 · 历史补查首次推荐
Keywords

系统论文 · KV cache / LLM agents / tool use / inference

研究问题

Agentic 语言模型反复以不同组合与顺序编码跨请求重复的工具与技能 schema，使标准前缀缓存无法复用其 KV 状态。

核心贡献

ReCache 独立缓存资源表示并降低推理计算/内存开销：资源级注意力移除跨资源交互并分配资源局部位置，产生组合不变的 KV 块；将资源可见性限制到贡献选择的层-KV头组路由，经结构/语义剪枝仅保留调用关键字段。

结果与条件

资源级注意力匹配稠密调用性能(82.3% vs 82.4% Inv-F1)并获3.655倍首token延迟加速；完整框架分配KV张量内存降92.43%、注意力加速1.423倍。

7 个公开工具/技能数据集基准含资源不相交测试。

AudioTETRIS：基于过渡重要性信号的音频 LLM Token 消除

2026-10-09
Keywords

方法论文 · audio LLM / token compression / speech / inference efficiency

研究问题

标准音频编码器对短片段也产生数百 token，自注意力随序列二次增长导致推理计算膨胀；现有训练免费压缩基于粗注意力/特征相似度剪枝或合并，将音频 token 视为各向同性特征会抹平频谱过渡，破坏语音解码所需的细粒度音素过渡。

核心贡献

AudioTETRIS 训练免费两阶段框架：先以编码器表示几何作为声学先验衡量 token 重要性，再应用注意力压缩；将先验传播进 LLM 解码器计算逐 token 融合分数，跨解码器层渐进 top-k 选择，无需额外训练或辅助模型。

结果与条件

Qwen2-Audio-7B、Phi-4-Multimodal、Audio Flamingo 3 上仅用 25% 音频 token 在多项语音任务保持近无损性能，中等压缩率匹配或超越全 token 精度，一致优于现有训练免费基线。

语音token信息密度峰值在声学过渡处；渐进跨层选择。

为什么读　音频token压缩忽略频谱过渡结构

主要限制　阅读范围：官方摘要，未读全文。具体任务数值未在摘要给出。

阅读建议　音频 token 压缩应利用频谱过渡结构；关注解码器内融合评分。

Microsoft StudentSim：模拟学生学习以改进 AI 辅导

2026-10-13
解决什么问题

AI 辅导工具需学生反馈改进，但真人学习研究缓慢、昂贵且难扩展；角色扮演学生模拟器难保真实能力边界，知识追踪模型又不接受自然语言导师输入。

技术变化

StudentSim 从公开去标识化学习者记录训练个性化 AI 学生模拟器：两阶段训练(先跨学生池化学习共性，再按个体记录特化)；以行为保真度(匹配记录响应)与引导响应性(读导师引导后更新)二维评估，建立 StudentSimEval 基准(国际象棋/二语英语写作/数学)；并用学生模拟器奖励训练 AI 导师。

价值与适用条件

仅用公开研究用途去标识化记录，无个人身份信息；研究系统非产品、不部署教室、不替代教师。

为什么读　真人学生研究慢且难扩展

NVIDIA ReplaySSM：重构混合模型 SSM 状态存储加速解码

2026-10-13
解决什么问题

混合模型以固定大小 SSM 状态替代 KV 缓存，但在服务批规模下 SSM 层反而成为延迟瓶颈，且复杂化投机解码与量化两种加速技术。

技术变化

ReplaySSM 将 SSM 状态表示为 checkpoint+近期输入 buffer，分离输出计算与状态更新：非冲刷步仅计算输出，缓冲满时一次冲刷更新 checkpoint；简化投机解码回滚(追加草稿输入而非快照状态)；高精度 checkpoint 用于递推、低精度副本用于读取，限制量化误差累积。

价值与适用条件

批256下SSM解码kernel提速1.46×~1.80×；百亿级混合模型投机解码吞吐1.85×~2.10×；NVFP4读取+高精度递推使多数模型GPQA-Diamond精度接近FP32约2个百分点内；已集成TensorRT-LLM/vLLM/SGLang/FlashInfer并进入生产。

官方NVIDIA技术博客(2026-10-13)；批规模1下无加速；L=16窗口最优。

主要限制　批规模1无加速；博客为NVIDIA自身评测。

阅读建议　长上下文混合模型服务者关注状态流量减半与投机解码吞吐收益；量化关注分离精度方案。
